## What is the difference between Low Code and Full Code versions of the project?

There are two ways to work on this project:

1. **Full-code way**: The full code way is to write the solution code from scratch and only submit a final Jupyter notebook with all the insights and observations.

2. **Low-code way**: The low-code way is to use an existing solution notebook template to build the solution and then submit a business report with insights and recommendations.

The primary purpose of providing these two options is to allow learners to opt for the approach that aligns with their individual learning aspirations and outcomes. The below table elaborates on these two options.

**Note:** If you submit a report along with the notebook, ONLY the report will be evaluated. Please make sure that all the sections mentioned in the rubric have been covered in your submission.

---

## Can I switch between Low Code and Full Code after Milestone submission?

No. It is highly advised that you complete the capstone journey with the version you choose initially.

---

## Is there a template for the project report to be submitted for Low Code that can be followed?

Yes, the report template with detailed instructions has been provided. You can follow the same. The sections mentioned there must be included in the report. However, please note that it is to help you get started with the project report. You can be creative with the report if you want. Therefore, we have also provided a sample report for a different problem statement. You can find the same in the section "Sample Capstone Project: Carbon Emissions Forecasting".

---

## Will the solution notebook be released for the capstone project?

The solution notebooks are not released to maintain the novelty of the capstone projects. You need to come up with your solution and techniques to solve the problem and you can get feedback on the same during project evaluations and final live presentations.

---

## Which format needs to be used to submit the files?

- **Low Code**: The project report can be submitted in a .pdf format
- **Full Code**: The Python notebook needs to be submitted in HTML format

---

## Can the Milestone solution be improved after submission to present it as a final submission?

You can work on different sections of the milestone to improve upon the final submission but please note that the scores of the milestone will not be changed once released.

---

## Will there be written and individual feedback for the Milestone submission?

Yes, similar to project evaluation, the milestone will be evaluated and the feedback will be shared on each section of the rubric.

---

## Is this a group project or does every individual have to identify and implement a project?

The Capstone project is an individual project and learners need to complete the project individually but will get an opportunity to interact with peers who are working on the same project through Slack channels guided by an industry mentor.
